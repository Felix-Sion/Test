贪吃蛇 · Snake Arcade 1.3.0
Windows x64 免安装版

启动方法：
双击 SnakeGame.exe 即可开始游戏，无需另外安装 Java。

重要：
SnakeGame.exe、app、runtime 和 native 文件夹需要放在同一目录。
请移动或复制整个 SnakeGame 文件夹，不要只复制 EXE 文件。
如果收到的是 ZIP 文件，请先完整解压，然后运行 SnakeGame.exe。

操作：
方向键 / WASD：移动
Enter / 空格：开始、暂停、继续
R：重新开始
M：开启 / 关闭背景音乐，也可点击“音乐：开 / 关”按钮
F8：应用 / 恢复原生颜色热补丁，蛇在薄荷绿和紫色之间切换
三种难度：悠闲、标准、挑战。每局开始后难度固定，结束后可切换。
切换窗口时自动暂停，回到游戏后按空格继续。
背景音乐为 A Walk in the Woods，已内置并循环播放。
暂停游戏或切换窗口时音乐暂停，继续时从原位置恢复。

原生热补丁：
点击“应用补丁 [F8]”后，游戏修改自带 DLL 内取色函数的入口机器码，
通过无条件 JMP 跳到紫色补丁函数；再次按 F8 恢复原始机器码。
无需重启或重开本局，不改变计分、难度和排行榜规则。
点击“查看机器码”查看实时入口字节、进程 PID 和函数地址。
补丁只在当前进程内生效，下次启动恢复薄荷绿。

存档：
三种难度分别记录前三名，按得分从高到低排列。
游戏结束、重开或关闭窗口时登记本局成绩，每局只登记一次；0 分不入榜。
不同对局的同分成绩可分别占位。
排行榜保存在本文件夹中的 data/leaderboards.properties。
旧版 best-score.txt 保留为未分类的历史综合纪录，不混入新的排行榜。
请解压到可写目录，例如 E:\Games\SnakeGame。

文件说明：
SnakeGame.exe：Windows 游戏启动程序
app：游戏代码与启动配置
runtime：游戏自带的 Java 运行环境，请保留
native：原生颜色热补丁 DLL，请保留；不需要安装 C 编译器
data：三种难度的前三名及旧版历史记录
