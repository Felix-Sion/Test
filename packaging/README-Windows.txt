贪吃蛇 · Snake Arcade 1.1.0
Windows x64 免安装版

启动方法：
双击 SnakeGame.exe 即可开始游戏，无需另外安装 Java。

重要：
SnakeGame.exe、app 文件夹和 runtime 文件夹需要放在同一目录。
请移动或复制整个 SnakeGame 文件夹，不要只复制 EXE 文件。
如果收到的是 ZIP 文件，请先完整解压，然后运行 SnakeGame.exe。

操作：
方向键 / WASD：移动
Enter / 空格：开始、暂停、继续
R：重新开始
三种难度：悠闲、标准、挑战。每局开始后难度固定，结束后可切换。
切换窗口时自动暂停，回到游戏后按空格继续。

存档：
三种难度分别记录前三名，按得分从高到低排列。
游戏结束、重开或关闭窗口时登记本局成绩，每局只登记一次；0 分不入榜。
不同对局的同分成绩可分别占位。
排行榜保存在本文件夹中的 data/leaderboards.properties。
旧版 best-score.txt 保留为未分类的历史综合纪录，不混入新的排行榜。
请解压到可写目录，例如 E:\Games\SnakeGame。

文件说明：
SnakeGame.exe：Windows 游戏启动程序
app：游戏代码与启动配置
runtime：游戏自带的 Java 运行环境，请保留
data：三种难度的前三名及旧版历史记录
